Quick help
  • Next eye: show → pair morph (red/blue) → hide
  • Current eye: show → mono morph (grey) → hide
  • Shared tones stay lit during morph; exclusives pulse
  • Path: Set path → click A then B · drag ends · Play path run
  • Shift+click = chord shape (white ring). One fretted note per string.
  • Shift+right-click = scale extras (cyan ring). Any frets — melody / colour notes for scale detect.
  • DETECT Chord = shape only · Scale = shape + extras · chips = freehand
  • Neck zoom: scroll = pan · Ctrl+scroll = zoom · drag fret numbers · double-click a note to centre · Reset in Display
  • Keys: ←→ step · Space play prog · M toggle pair morph · P set/clear path · Esc exit focus · ? this help
