1. What this tool is for

The Fretboard is the practice neck. It shows where a short progression sits on guitar or bass, how one chord moves to the next, and how a grip names itself.

It is not the song editor. The three tools share one song:

ToolJob
Harmonic LandscapeCompose the cell — any length, multi-key, versions, From here.
ArrangementOrder cells into form (verse / chorus, reps, seams).
FretboardFrets for a window of at most 8 chords.
Quick start (alone): Open the app → leave C–G–Am–F → click frets to hear notes → watch current vs next. Press ? for the spotlight tour.
Quick start (from a song): In Landscape, select a step near the bit you want to fret → open Fretboard. You get a window of up to 8 chords around that step. Edit shapes here; send back when done.

2. In-app tour

Same idea as Help on the ear trainer: a spotlight walks the real controls. In the app press ?, or the ? on the legend, or Take the tour on the tip bar.

  • → / Enter — next · ← — back · Esc — leave
  • The written page you are on is the full reference. The tour is the five-minute walk.

3. Landscape & Arrangement

Header row: Landscape · Arrangement · Pull session.

The 8-chord window

Fretboard cannot hold a ninth slot. Landscape / Arrangement send a window of 8 around the focused step — not always the first eight. Coming back, that window is spliced into the same place in the full cell. The rest of the song stays put.

If you delete a slot here, only that window shortens. The tail of a long Landscape cell is not thrown away.

Scale / key is a viewing lens

The Scale / Key dropdowns colour the neck (amber diamonds, romans). They are not the song’s write-home. Opening Fretboard must not flip Landscape to C major or slide the path onto the wrong Chase disk. If a cell ever looks “moved,” go back to Landscape, set Write home to the real key, and click On this wheel (notes stay; only the disk changes).

What each button does

ButtonResult
LandscapeSaves this window into the shared song and opens Landscape on that cell.
ArrangementOpens form view. Same session.
Pull sessionReload the focused Landscape cell (again clipped to 8).

Shared store: browser localStorage key idlehanz_song_v1. Same origin / Desktop folder layout.

5. Reading the board

Thickest string is at the bottom (low pitch). Open notes sit left of the nut.

MarkMeaning
RedCurrent slot (the one you focused)
BlueNext slot in the progression
Split red|blueTone shared by current and next
Amber diamondScale tone (Scale map = Full)
Gold ringRoot emphasis
White hollow ringShape-capture pin (Shift+click) — one per string
Cyan ringScale extra (Shift+right-click) — melody / colour notes
Amber numberArpeggio order on a path (chord mode)
A / BPath endpoints (drag when the path is set)

Interval colours (hybrid): fill = function (R, 3, ♭3, 5…). Outer ring is still current vs next.

6. Progression (max 8)

Under the board. Default demo is C–G–Am–F if you did not come from Landscape.

  • Click a slot — it becomes current; the following slot is next.
  • Named / Custom — root + quality, or a free pitch set (round-trips as custom + notes).
  • Bass / slash — root, a chord tone, or any bass note.
  • Eye — show / morph / hide (see Morph).
  • Add / Solo / All — add a slot (stops at 8), solo the focused chord, or show everything again.

← → step focus when you are not typing in a field.

7. Scale / key is a lens

Right column: root + scale type (major modes, minor, pentatonic, exotic…). That set drives amber diamonds, “in scale” open strings, and roman numerals on slots.

Changing Scale / Key here does not transpose the song and must not rewrite Landscape’s write-home. Think “what map am I practising on,” not “what key is the piece.”

8. Tuning & instrument

  • Instrument: Guitar or Bass.
  • Strings: guitar 6–8, bass 4–6.
  • Presets: Standard, Drop D, Baritone B, and more. Blue highlight matches the actual open tuning.
  • Custom: pickers are low→high left to right (thick/low on the left). Board top is still the high string.
Shape-capture pins follow sounding notes if you change tuning: they move fret on the same string.

10. Audio

  • Click a fret — that pitch.
  • Play / Stop — walk visible slots with the chosen pattern.
  • ◀ ▶ — step and play one chord.
  • Pattern: Strum, Arpeggio, Block, Root only.
  • Tempo, loop, volume, octave.

Space toggles play when focus is not on a button.

Browsers mute until you click once. Click any fret if you hear nothing.

11. Voice-leading morph

How notes move current → next. Shared tones stay lit. Exclusive tones pulse.

EyeCycleLook
Next slot Show → pair morph → Hide Red / blue (roles)
Current slot Show → mono morph → Hide Greyscale (shape only)
  • Only one morph mode at a time.
  • Speed ½× / 1× / 2× under the legend.
  • Hybrid interval fill and scale diamonds hide while morphing.
  • Stops for Play and Solo.

M toggles pair morph.

12. Detect & shape capture

On the board

  • Shift+click a fretted note → white ring. One pin per string (a grip). Same spot again = remove. Another fret on that string = move.
  • Shift+right-click → cyan extra (melody / colour). Any number of frets.

DETECT panel

  • Chord mode uses shape pins (or freehand chips).
  • Scale mode uses shape + extras (or chips). Optional mode-root pin.
  • From pair / From progression seed chips from the slots (clears pins).
  • Apply as chord writes the top match into the focused slot.
  • Apply as scale / key writes the lens (Scale / Key), not Landscape write-home.
Example: Finger a B major grip → Shift+click each fretted note up the strings → DETECT should offer B Major → Apply as chord.

13. Path spotlight & arps

  1. Set path → click start (A), then end (B).
  2. Outside the corridor dims.
  3. Width: Narrow / Normal (~3 frets) / Wide.
  4. Play mode: Scale run / Chord arp / Scale + arp. Direction: Up / Down / Up-down.
  5. Play path auditions the corridor.
  6. Drag A, B, or the beam to move it.

P set/clear. Touch-drag works on the handles.

14. Save, load & export

  • Name in the header. Save / Load / Delete — this browser’s list.
  • Export / Import JSON — a file you can keep.
  • Last session restores on reopen. Dirty sessions show *.
  • Export PNG — diagram plus caption (chords, key, path/morph flags).

That list is the Fretboard’s own practice snapshots. The song lives in the shared Landscape session.

17. FAQ

No sound?

Click the board once (browser unlock), then raise Volume / check Octave.

Why did Landscape jump to C major / the wrong wheel?

Older builds let Fretboard’s default C lens rewrite the song key. Current builds must not. If a session is already stuck: Landscape → set Write home to the real key → On this wheel (notes stay, disk moves).

I only see eight chords of a long cell?

That is the cap. You have a window around the step you had selected. The full cell is still in Landscape.

Why did scale diamonds vanish?

Scale map is Off or Chord notes only — or morph is running.

Shift+click ate a note I already had?

Old builds toggled pitch class globally. Now a pin is one fretted place, one per string.

Is anything uploaded?

No. Sessions stay in this browser unless you export a file.

Phone?

Tablet or desktop is better. Path handles take touch; zoom wants a scroll wheel or trackpad.
