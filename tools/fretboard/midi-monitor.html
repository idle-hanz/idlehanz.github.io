MIDI monitor

Dump what Fender Studio / Studio One actually sends. Chase stays off until this log exists. Chrome or Edge only. Clock = tempo. SPP = song time. MTC is the fallback if SPP is junk.

DAW setup — do this once
  1. 1Install loopMIDI (free, Tobias Erichsen) and create a port named Idle Hanz Chase. Leave it running. Do not buy a hardware MIDI interface for this.
  2. 2Fender Studio / Studio One → Options (Windows) → External Devices → Add → New Instrument. Name it Idle Hanz Chase. Send To = that loopMIDI port. Tick Send MIDI Clock and Use MIDI Clock Start. If you also see Send MIDI Time Code, tick it so we can measure MTC. Receive From can stay empty.
  3. 3Open this page in Chrome or Edge (not Firefox). Click Enable Web MIDI, allow the prompt, pick Idle Hanz Chase.
  4. 4Use the Mark buttons below, then play the song in the DAW. We need: play from bar 1, stop, play from bar 17 (or any mid-song locate), cycle wrap, and a tempo change if easy.
  5. 5Copy log and paste it back in the chase chat. Raw hex + timestamps — do not paraphrase.

If no clock appears after play: confirm loopMIDI is running, the External Device Send To is that port, and you allowed MIDI in the browser. A dummy instrument track routed to the device is only needed if the DAW stays silent. This logger does not lock the Fretboard row.
